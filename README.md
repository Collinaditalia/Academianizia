# Academia da Nizia

Projeto web simples feito em HTML, CSS e JavaScript.

## Estrutura
- `index.html`
- `assets/css/style.css`
- `assets/js/script.js`
- `assets/gifs/`
- `assets/images/`

## Como usar
1. Abra o `index.html` no navegador.
2. Adicione os GIFs na pasta `assets/gifs/`.
3. Publique no GitHub Pages se quiser colocar online.
