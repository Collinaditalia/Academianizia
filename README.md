# Academia da Nizia

Aplicativo web estático para treino em casa, com agenda semanal de segunda a domingo às 16:00, cronômetro, progresso e exercícios guiados com GIFs ou sequências de imagens locais.

## Funcionalidades

- Treino diário de segunda a domingo
- Horário padrão: 16:00
- Dashboard com progresso semanal
- Agenda editável salva no navegador com `localStorage`
- Cronômetro com som ao finalizar
- Exercícios com GIFs locais e sequências de imagens
- Layout responsivo
- Pronto para publicação no GitHub Pages
